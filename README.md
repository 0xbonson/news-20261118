This repository contains an entry for the [make.fun news-image bounty competition](https://make.fun/bounty/news-image-20261118).

## Overview

This entry was produced by an AI coding agent for make.fun's news-image competition. The program copies one binary image file into the output directory under the name `entry.png`.

The shipped picture is the original work of the entrant and is preserved completely intact, without any alteration, redrawing, or modification by the program.

## Local Execution

The application is built to run on Node.js 22 using only standard library modules.

To execute the program locally and write the image to an output directory, run:

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
